Arqen AI Studio – Privacy Policy

Last updated: September 27, 2026

Arqen AI Studio ("the tool") is a private video production tool operated by Stefan Semb ("I", "me") for the YouTube channel Arqen Build (@arqenbuild). The tool runs locally on my own computer and is used only by me, only with my own YouTube channel.

Use of YouTube API Services

The tool uses YouTube API Services to upload videos, set thumbnails, manage playlists and update branding settings on my own channel. By using the tool you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

What data is accessed

  • An OAuth access and refresh token for my Google account, granted through Google's consent screen.
  • My channel's id and title, and the titles and ids of my channel's playlists.

The tool does not access comments, analytics, subscribers, watch history or any data belonging to other users or channels.

How data is used

This data is used only to operate the tool: to show which channel is connected, to upload and schedule videos I have approved, to set their thumbnails and to add them to playlists.

Storage and sharing

Tokens and channel information are stored in local files on my own computer. They are not sent to any server other than Google's, are not shared with, sold to or disclosed to any third party, and are not used for advertising. Video content and metadata are processed by third-party services I use for production (text generation and text-to-speech); no YouTube API data is sent to these services.

Retention and deletion

Stored tokens and channel information are deleted when I disconnect YouTube in the tool. Access can also be revoked at any time at Google security settings (myaccount.google.com/permissions), after which the tool can no longer access the account. Any remaining locally stored YouTube API data is deleted within 30 days of revocation.

Cookies

The tool does not use cookies or similar technologies to collect information about anyone.
